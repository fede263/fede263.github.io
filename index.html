01Embedded Systems · Team of 4 · 2025

IoT Networked Maths Quiz

A quiz game spread across two networked Raspberry Pi Pico W microcontrollers. Users answer maths questions on a physical keypad; the first Pico checks the answer and sends the result over MQTT, and the second Pico lights an RGB LED green or red.

MicroPythonRaspberry Pi Pico WMQTTGPIOPWMFlaskHTML/CSS
My role, challenges & skills

My role

  • Programmed the input Pico: scanning the 4×3 keypad matrix and checking answers.
  • Programmed the output Pico: receiving results over MQTT and driving the RGB LED with PWM.
  • Built the HTML/CSS website and co-wrote the project report.

Challenges

  • Wi-Fi and MQTT connections sometimes dropped, so I added retry and automatic reconnection logic.
  • Reading a keypad matrix reliably, using a polling delay so one press isn't counted many times.

Skills developed

  • Hardware interfacing (GPIO, PWM)
  • Publish/subscribe messaging
  • Designing for reliability
  • Team integration

Project Nova

A two-player, turn-based strategy game with a Swing GUI. Players search a hidden grid for creatures: +5 for a hit, +10 for a whole creature, and the game announces a winner once all are found. Games can be saved and loaded.

JavaSwingOOPSerialisation
My role, challenges & skills

My role

  • Designed and built the whole game myself.
  • Split the code into Game, Board, Player and Creature classes, plus GUI and file-handling classes.
  • Built the menus, help screen, game grid and live scores.

Challenges

  • Placing creatures randomly without overlapping or leaving the grid: I wrote a check that each shape fits first.
  • Saving the whole game state: solved with Java serialisation and clear error messages.

Skills developed

  • Object-oriented design
  • Event-driven GUIs
  • File I/O & error handling
  • Working independently

# Drive each row high, then check which column reads high
def scan_keypad():
    for r, row in enumerate(rows):
        row.value(1)
        for c, col in enumerate(cols):
            if col.value():
                row.value(0)
                return KEYS[r][c]
        row.value(0)
    return None
